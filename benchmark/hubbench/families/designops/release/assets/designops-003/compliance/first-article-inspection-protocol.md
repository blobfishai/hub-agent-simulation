# First-article inspection protocol (extract)

- A Class I first-article run inspects the first production part on the CMM (300 minutes for the gear housing) followed by 60 minutes of line changeover.
- The run is continuous: it may not be split across windows on different days.
- A CMM-capable line (probe module attached) must be assigned for the full duration; only lines flagged on the roster are eligible.
- Runs longer than a window (4 h) require both windows of one line on one day.
- Fixture sets required: one set per station on the assigned line, calibrated and built to the current revision.
