# Rollback rehearsal protocol (extract)

- A full-page release deploys the page (300 minutes for the product tour) followed by 60 minutes of rollback rehearsal and verification.
- The run is continuous: it may not be split across windows on different days.
- A lane with instant-rollback snapshots must be assigned for the full run; only lanes flagged on the roster are eligible.
- Runs longer than a window (4 h) require both windows of one lane on one day.
