# Skyfield Commerce Cloud — transmission terms (extract)

Standard redelivery: the next scheduled 18:00 transmission on the confirmed date. Expedited: out-of-cycle push, USD 260 flat per file set. Files landing after the customer's 02:00 cutoff validate the following night and load the next batch day.

Confirmations are valid until the date printed on them. Superseded confirmations (for example SC-9711) must not be used for planning.
