# Certification program PRG-SNS7 — scope note

Certificates under PRG-SNS7 cover the sensor pod and mast configurations at the listed component revisions. A Class I change on a listed component invalidates the certificate; a re-certification report from the accredited laboratory is required before cut-in. An interim deviation requires the change control board chair and written notification to the regulator; the deviation is not delegated. Class II changes do not affect the scope.
