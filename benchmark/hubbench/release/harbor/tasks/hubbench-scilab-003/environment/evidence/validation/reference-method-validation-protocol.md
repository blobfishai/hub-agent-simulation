# Reference-method validation protocol (extract)

- A full HbA1c validation runs the 3-plate reference set (360 minutes) followed by 60 minutes of evidence capture.
- The run is continuous: it may not be split across windows on different days.
- An analyser with current operational qualification must be assigned for the full duration; only analysers flagged on the roster are eligible.
- Runs longer than a window (4 h) require both windows of one analyser on one day.
